## Scope and original evidence

N3 gives observed medians and ranges, with no p95, confidence interval, SLA, capacity/headroom claim or general speedup claim. This performance fixture is SDR/CFR1080p; long, UHD, HDR and VFR correctness belong to separate release checks. No historical N20 or old-tool N3 timings are pooled with this new common-tool pair. RSS was sampled every 100 ms and may miss short peaks; summed RSS includes shared pages. Cgroup memory includes page cache, and lifetime peaks include startup/warmup. See the summary's full limitations and [original resource samples](https://github.com/Kay0k1/cutmyvideo-core/blob/faccc12e510fdb57c112f2df76a6bedb14b1d5fb/verification/2026-10-11-current-pair-common-tools-n3/raw/pair/resources.jsonl.gz).

Collection verified its exact digest and all 2,647 regular-file CRCs; bounded extraction yielded 875,163,207 bytes. This publication selects original metadata and journals.
